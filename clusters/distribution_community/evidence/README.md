# Evidence Artifacts

Store inspectable distribution and community evidence here.

Preferred artifacts:

- `raw.jsonl`: source records with stable evidence identifiers, URLs, excerpts,
  visible counts, queries, capture metadata, and source-access status
- `normalized.jsonl`: optional normalized surface and artifact records retaining
  raw identifiers and missing-data reasons
- `profile.csv`: optional spreadsheet-friendly derived profile

`PROFILE.md` remains the human-readable cluster summary. Do not overwrite raw
records with normalized or summarized data. Planning specifications and API
assessments are context, not evidence artifacts.
