# Agent Tooling

This directory contains third-party assistant skills installed from
`JuliusBrussee/caveman`. `skills-lock.json` records their source paths and
content hashes.

These files document assistant behavior; they are not Market Gap Finder research
specifications. Project knowledge starts at [Documentation Index](../docs/index.md).

Installed skill directories:

- `caveman`
- `caveman-commit`
- `caveman-compress`
- `caveman-help`
- `caveman-review`
- `caveman-stats`
- `cavecrew`

`cavecrew` describes optional subagent roles, but corresponding agent prompt
files are not present in this checkout.
