# Cluster Record Catalog

This catalog preserves proposed logical records and field names from cluster
planning. It is a conceptual interoperability reference, not an implemented
database or Python schema. Fields remain nullable unless a source and record type
require them. Shared provenance fields come from
[Evidence and Lineage](evidence-lineage.md).
